Voice server · online / self-hosted

Everyone in a room must use the same server address. Self-hosting below sets this PC up automatically. The default service is unchanged.

Host a server with ngrok

One-time setup: install the official ngrok CLI, then run ngrok config add-authtoken YOUR_TOKEN in a terminal. The app starts its current voice server and ngrok, then gives you a shareable HTTPS address. Your token stays in ngrok's own config.

Anyone who gets the address can reach the server while it is running. Share it only with your group; stop hosting when the match is over.
